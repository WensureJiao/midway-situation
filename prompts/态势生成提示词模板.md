# 中途岛战役态势界面生成提示词模板

## 用法

```
输入 = 时间片清洗数据摘要 + 场景简述 + System 提示词
输出 = SituationViewSpec（JSON）→ 前端地图 + 固定统计图
```

本仓库在 `src/lib/prompts.ts` 中实现了可运行模板。

## System（约束输出形态）

见代码常量 `SITUATION_SYSTEM_PROMPT`，核心要求：

1. **只输出 JSON**（SituationViewSpec），不要 Markdown 解释。
2. **地图为主界面**：给出 center / zoom / highlight_names / axes / threat_zones。
3. **固定四张统计图**（服务端用清洗数据覆盖）：水面舰艇、在空飞机、蓝/红舰载机就绪构成。
4. **不输出文字研判面板**：intent_findings / threat_findings / priorities / threat_ratings 为空数组。
5. **防幻觉**：坐标来自清洗数据；飞龙等缺失舰体标注“未知”，不得直接判沉。

## User 插槽

| 插槽 | 来源 |
|------|------|
| `scenario` / `time_slice` / `phase_label` | 切片元数据 |
| `situation_brief` / `threat_context` | pack 内场景背景（仅作叙述参考） |
| `data_summary` | 由 `summarizePackForPrompt` 压缩的舰艇/在空机几何 |

## 本地回退

无 `OPENAI_API_KEY` 时，`mode=llm` 会回退到确定性本地生成器（`generateSituationLocal`），保证测试链路可跑通。

## 输出范围

本模板生成 **态势地图 + 固定统计图 + 威胁等级图**；不展示意图/威胁文字研判面板。
