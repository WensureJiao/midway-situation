# 中途岛战役态势界面生成提示词模板

## 用法

```
输入 = 时间片清洗数据摘要 + 意图研判/威胁分析任务
输出 = SituationViewSpec（JSON）→ 前端地图 + 统计图渲染
```

本仓库在 `src/lib/prompts.ts` 中实现了可运行模板；测试台页面可一键组装并预览。

## System（约束输出形态）

见代码常量 `SITUATION_SYSTEM_PROMPT`，核心要求：

1. **只输出 JSON**（SituationViewSpec），不要 Markdown 解释。
2. **地图为主界面**：给出 center / zoom / highlight_names / axes / threat_zones。
3. **配常见统计图**：兵力对比、在空机型、威胁/运动/就绪等 bar/pie。
4. **结论可追溯任务**：intent_findings / threat_findings 绑定 `task_id`。
5. **防幻觉**：坐标来自清洗数据；飞龙等缺失舰体标注“未知”，不得直接判沉。

## User 插槽

| 插槽 | 来源 |
|------|------|
| `scenario` / `time_slice` / `phase_label` | 切片元数据 |
| `situation_brief` / `threat_context` | 意图/威胁文件 |
| `data_summary` | 由 `summarizePackForPrompt` 压缩的舰艇/在空机几何 |
| `tasks` | 勾选的 INT/THR 任务（含 prompt、hints、reference） |

## 与六项能力的对应

- 意图：佯动与真实打击区分、作战方向判断、行动阶段推断
- 威胁：关键威胁目标筛选、威胁等级评估、目标优先级排序

生成结果分别落入 findings、threat_ratings、priorities，并投影到地图高亮与轴线。

## 本地回退

无 `OPENAI_API_KEY` 时，`mode=llm` 会回退到确定性本地生成器（`generateSituationLocal`），保证测试链路可跑通。
