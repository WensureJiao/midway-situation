# VMMP 范式引入效果分析报告

**日期**：2026-09-19  
**对照**：A = 无范式；B = 注入 VMMP（威胁 `VMMP_W` / 意图 `VMMP_I`）  
**模型**：通义 qwen-plus  
**材料**：`docs/vmmp_reasoning/`、`docs/vmmp_ab_test/`、`/compare` 与 `public/data/vmmp_ab_visual/`

---

## 报告结构说明

本报告按三步展开：

1. **推理流程对比**——范式是否使推理严格按 **CROTME** 规范化；  
2. **态势图对比**——生成画面有何差异（**截图位已预留，请自行粘贴**）；  
3. **任务结论对比**——威胁分析 vs 意图研判，哪类结论更完善、更贴合观测者意图。

> 记号说明：文中 **CROTME** = Cognitive elements / Relations / Operations / Topology–Mapping / Evaluation，对应范式中的 C、R、O、T/M、E。

# 一、推理流程对比：范式使推理严格按 CROTME 规范化

## 1.1 两条路径（范式规定）

| 任务 | reasoning_path（O） | 认知重点（C/R） |
|------|---------------------|-----------------|
| 威胁分析 `VMMP_W` | Identify → Locate → Filter → Compare → Aggregate → Assess → Rank → Verify | 实体、能力、威胁等级、优先级；空间比较、筛选、排序 |
| 意图研判 `VMMP_I` | Identify → Trace → Compare → Relate → Infer → Verify | 行为、证据、假设、意图、置信度；时间、方向、支持/证伪 |

规范化的完整闭环是：

```
C（看什么）→ R（什么关系）→ O（按路径逐步操作）→ M（落到画面）→ E（自检）
```

## 1.2 A 组：自由推理，结构松散

A 组**不注入** VMMP JSON，模型通常：

- 直接写判断（谁危险、指向哪里、阶段如何）；  
- 偶有分析，但**没有固定步骤名**，也**不显式声明 C / R / O / M / E**；  
- 容易从「结论」倒推「该画什么」，中间缺少可复核的操作链。

**例 · T1 威胁 A（节选）**

> 红方四航母中……整体打击潜力最大。  
> 优先级按开战后首波打击能力排：……  
> 态势图突出红方四航母坐标……

→ 有结论、有排序意向，但**看不到 Identify / Filter / Rank / Verify** 等步骤，也未区分「认知要素」与「映射规则」。

**例 · T1 意图 A（节选）**

> 红方三航母呈品字形向中途岛逼近……是主攻态势。  
> 蓝方四艘日舰停泊集结……属佯动牵制配置。  
> 作战方向锁定中途岛，行动阶段处于进攻展开初期……

→ 直接给出佯动/方向/阶段结论，**缺少 Trace → Relate → Infer → Verify** 的可追溯链（且该条 A 对红蓝角色表述本身也易混，说明无范式时结论更不稳）。

## 1.3 B 组：严格按 CROTME 走完再落图

B 组注入对应 VMMP 后，五个切片（T1 / T21 / T81 / T145 / T193）的威胁与意图回复，普遍呈现同一骨架：

| 环节 | B 组实际写法 | 规范化作用 |
|------|--------------|------------|
| **C** | 先列出 CombatEntity / State / Evidence 等 | 限定「这次该看什么」，避免一上来就下结论 |
| **R** | 写 Spatial / Comparative / Directional 等 | 明确用哪种关系组织证据 |
| **O** | 逐步写出路径上的每一步（带步骤名） | 推理顺序固定，可对表检查是否跳步 |
| **M** | 说明高亮、轴线、威胁圈、排序如何对应 | 认知 → 视觉有对应规则，不是随意美化 |
| **E** | 用坐标/航向/就绪数等回锚本切片 | 自检，减少跨切片「剧透」 |

**例 · T1 威胁 B（结构摘要）**

- C：红方四航母 + 蓝方三航母为远程打击实体  
- R：舰载数量 vs 在航/停泊呈反向关联  
- O：Identify → Locate → Filter → Compare → Aggregate → Assess → Rank → Verify（逐步写出）  
- M：高亮「在航 + 高舰载」组合，轴线连中途岛—集结区  

**例 · T1 意图 B（结构摘要）**

- C：双方航母初始部署状态  
- R：航向 112.5° vs 245°–284° 的不对称接触前态势  
- O：Identify → Trace → Compare → Relate → Infer → Verify  
- M：两条航向轴交汇；讨论停泊舰是否构成佯动  
- E：锚定 T1 坐标/航向，不引入后续切片  

## 1.4 五切片一览（是否规范化）

| 切片 | 威胁 B · CROTME | 意图 B · CROTME | A 组对照 |
|------|-----------------|-----------------|----------|
| T1 初始 | 是（末尾偶有截断） | 是 | 直接结论 |
| T21 搜索 | 是 | 是 | 跳过 Filter/Rank 等 |
| T81 机库 | 是 | 是（Infer 内容可商榷，但路径在） | 缺完整路径 |
| T145 残局 | 是（Rank 后偶截断） | 是 | 跳结论 |
| T193 终局 | 是 | 是 | 跳结论 |

**本节结论**

> **范式引进的首要收益是推理流程规范化**：B 组把「想」从自由散文，变成可对表检查的 **C → R → O → M → E**。  
> 这不等于每一步史实判断都正确，但意味着观测者可以按同一套认知操作复盘、比较、找跳步——这正是 CROTME 的工程价值。

# 三、任务结论对比：威胁分析 vs 意图研判，谁更完善、更贴观测者意图

本节比较的是**两个任务各自「该回答什么」是否被答全、答对位**，而不是比较「威胁和意图谁更重要」。

## 3.1 观测者意图分别是什么

| | 威胁分析（观测者意图） | 意图研判（观测者意图） |
|--|------------------------|------------------------|
| 核心问题 | 谁最危险？先盯谁？等级与优先级如何？ | 对方想干什么？指向哪？到哪一阶段？有无佯动？ |
| 完备结论应含 | 筛选后的关键目标、等级/层次、有序优先级、证据与不确定 | 方向假设、阶段判断、证据→假设（支持/证伪）、置信度 |
| 范式路径 | … → Filter → Aggregate → Assess → **Rank** → Verify | … → Trace → Relate → **Infer** → Verify |

## 3.2 无范式（A）时，两任务结论的完备性

| 维度 | 威胁 · A | 意图 · A |
|------|----------|----------|
| 能否给出可用结论 | 通常能（谁危险、大概排序） | 通常能（指向中途岛、集结等） |
| 结构完整性 | 常缺清晰「筛选→等级→排序」表格式输出 | 常缺「证据链 / 假设验证 / 阶段条」 |
| 与观测者意图对齐 | 偏「态势综述 + 威胁感」，排序有时含糊 | 偏「综合态势」，易与威胁叙述搅在一起 |
| 风险 | 结论像通用 COP，观测者要自己二次提炼优先级 | 结论像再讲一遍战场，观测者要自己抽「意图三问」 |

T1 预实验 E 均分（助手预评，非盲评）：威胁 A **3.63**；意图 A **3.38**。  
意图侧 Temporal / Evidence / Sequence 更弱——说明**无范式时意图任务更容易答「不完整」**。

## 3.3 有范式（B）时，两任务结论的完备性

| 维度 | 威胁 · B | 意图 · B |
|------|----------|----------|
| 结构 | 强制走到 Rank，优先级可对表 | 强制走到 Infer/Verify，假设可对表 |
| 与观测者意图 | 更贴「筛选—评估—排序」 | 更贴「方向—阶段—证据」 |
| E 均分（T1） | **4.63（+1.0）** | **4.75（+1.4）** |
| 提升最大处 | Ranking / Aggregation / Screening | Evidence / Sequence / Relation / Temporal |

含义：

- **威胁任务**：范式主要让「优先级结论」从含糊变可执行（谁第一、谁第二、依据是什么）。  
- **意图任务**：范式主要让「意图三问」从散文变可验证（证据是否支持/证伪假设，阶段如何锚定）。

相对 A 的提升幅度上，**意图任务受益更大（+1.4 vs +1.0）**——因为无范式时意图结论更容易「看起来什么都说了，但观测者真正要的三问并未结构化给出」。

## 3.4 哪个更完善、更符合观测者意图？——分层回答

**（1）就「有没有按观测者任务把结论答完整」而言**

| 任务 | 有范式后的完备性 | 判断 |
|------|------------------|------|
| 威胁分析 | 高：筛选、等级、排序链条清晰 | 完善 |
| 意图研判 | 高：方向、阶段、证据—假设链条清晰 | 完善；相对 A 的补全幅度往往更大 |

→ **两个任务在引入范式后都能更贴合各自观测者意图**；不是「威胁赢了意图」或反过来，而是**各自对齐了自己的问题**。

**（2）就「观测者拿结论能不能直接决策」而言**

- 威胁观测者要的是 **可排序的行动优先级** → B 的 Rank + 威胁主图更直接。  
- 意图观测者要的是 **可辩护的意图假设** → B 的 Infer/Verify + 阶段/轴线更直接。  

若硬比「哪份结论更完善」：  
- 看 **威胁决策完备性** → 威胁·B 更完善；  
- 看 **意图认知完备性** → 意图·B 更完善；  
- 看 **相对无范式的改善幅度** → **意图任务往往改善更明显**（证据链与顺序从弱到强）。

**（3）一句话总括**

> 范式并不让某一种任务「永远更优」，而是让**威胁结论更像威胁结论、意图结论更像意图结论**。  
> 对观测者而言：威胁分析在 B 下更适合「盯谁」；意图研判在 B 下更适合「对方想干什么」——二者互补；相对 A，意图侧从「综述」到「可验证意图」的跃迁通常更醒目。
