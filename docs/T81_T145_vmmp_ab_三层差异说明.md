## 4. 生成图表差异

### 4.0 选图思维流程（先想问题，再选图种）

图表层要证明的不是「B 图更多」，而是：**有 VMMP 时，会按任务问句走完「认知关系 → 视觉拓扑 → 图种」再落图；无范式时只保留常驻可比槽。**

写报告 / 读对比页时，按下面五步想：

```
① 这一片要回答什么？
   威胁：谁最急、等级怎么分、敌我相对岛在哪
   意图：阶段、指向、证据够不够

② 回答需要哪类认知操作？（R / O）
   Locate / Compare / Rank / Filter / Relate / Verify …

③ 这类操作该用哪种视觉拓扑编码？（T）
   Position 位置 · Alignment 对齐比较 · Ordering 排序
   Hierarchy/Grouping 分层归组 · Connection 关联 · Salience 显著性 …

④ 拓扑落到哪种统计图？（图种槽）
   Position → 散点（敌我×岛）
   Ordering+Salience → 横条排序
   Hierarchy/Grouping → 等级柱
   Position+Alignment → 方位雷达（相对岛的扇区强弱）
   Connection → 证据饼；Alignment → 证据轮廓雷达

⑤ 常驻还是扩展？
   常驻：A/B/本地都有，保证左右可比
   扩展：仅当 rich=有 VMMP，且 M 规则激活了对应拓扑才出现
```

对照实现（`vmmpChartSelect.ts`）：

| 任务 | 常驻（A 也有） | 扩展（仅 B，M 命中才出） |
|------|----------------|--------------------------|
| 威胁 | 散点（Position）· 横条排序（Ordering/Salience）· 等级柱（Hierarchy/Grouping） | **方位雷达**（Position+Alignment） |
| 意图 | （对比页意图图沉底；证据类为扩展） | 证据构成饼（Connection）；证据维度雷达（Alignment） |

**读图口令：**  
先看常驻三图是否同问句、同槽位——若数值分层不同，说明筛排结果不同；再看 B 多出的扩展图是否**对准任务几何**（威胁看相对岛方位，意图看证据结构），而不是「多一张好看的图」。

界面上扩展图旁有「选图：…」一行，对应上表 M→T→图种链条，可直接截进报告。

### 4.1 T81 威胁（最新预存图种）

| 图种 | A | B | 对应思维步 |
|------|---|---|------------|
| 敌我位置与登陆海域关系（散点） | ✓ | ✓ | ①② Locate → Position |
| 威胁目标排序（横条） | ✓ | ✓ | Rank → Ordering |
| 威胁等级分布（柱） | ✓ | ✓ | Aggregate/Assess → Grouping/Hierarchy |
| **相对中途岛方位分布（雷达）** | ✗ | **✓** | Compare+Locate → Alignment+Position（扩展） |

配图：图 15 对图 16。

**表述：**  
T81 威胁问句是「换弹窗口下谁最急、敌我相对岛如何」。常驻三图两边都有，保证可比；读排序条时看分层——A 含「四航母 + 已回收杰克式」等档，B 以三航母换弹为紧急顶档，与地图收缩一致。B 多出的方位雷达，是因为有 VMMP 后 M 激活了 Position/Alignment：把「相对中途岛的方位扇区」单独对齐比较，而不是只在散点里隐含距离。勿写成「B 图层多就更好」，应写「B 为空间比较补了专用图种」。

### 4.2 T145

问句换成残局：「伤航母与空中残余相对岛仍在哪一侧、威胁档怎么收」。图种结构同 4.1——常驻三图两边都有；**B 多方位雷达**（配图：图 17、图 18）。读法：常驻看排序/等级是否仍顶在赤城等伤舰；扩展雷达看日方残部相对中途岛的方位是否与地图蓝轴「→中途岛」同向。若只写「B 多一张雷达」而不点出「对准岛心几何」，选图论证就薄了。

### 4.3 一段收束（可粘贴）

> 图表层 A/B 共用常驻槽（散点·排序·等级），保证同问句可比；有 VMMP 的 B 再按 M→T 激活扩展图。威胁任务上稳定多出「相对中途岛方位」雷达，对应 Spatial/Comparative → Position/Alignment，把敌我相对岛的方位从散点里拆成可对齐比较的专用图。评价选图时看「是否对准任务几何」，不看图种数量。
