# 态势地图怎么读

左下角半透明条就是图例，和地图上的符号一一对应。读图时先看「谁在哪」，再看「圈」和「箭头」在强调什么。

## 颜色：先分敌我

- **美方（红方）**：水面偏砖红；在空飞机更偏浅红。
- **日方（蓝方）**：水面偏海蓝；在空飞机更偏浅蓝。
- **岸基设施**：金色（机场、防空等），不跟红蓝抢身份色。
- **损伤**：舰体偏橙，提示该单位已受损，仍按阵营位置落点。

## 单位形状：一眼认类型

| 图上长什么样 | 是什么 |
| --- | --- |
| 方块 | 航母 |
| 圆点 | 其他水面舰（战列、巡洋、驱逐等） |
| 小三角（会按航向转） | 在空飞机 |
| 金色十字跑道 | 机场 |
| 金色六边形 | 防空阵地 |
| 金色外沿 / 光晕 | **高亮**：当前研判要盯的关键单位 |

平时不铺满舰名，避免海图像便利贴。只有高亮单位悬停时会冒出名字；要点细节就点击。

## 圈：关注区与紧急区

虚线圆 = 模型认为「这块海要盯住」的范围，圆心常在航母群、集结点或岸基附近。

- **关注区**：橙金虚线、浅橙填充——一般关注（中/低威胁语境）。
- **紧急区**：酒红虚线、浅红填充——紧急盯防（等级为「紧急」）。

悬停圆圈可读：区名、是关注还是紧急、大约半径（海里）。  
做**威胁分析**时，先看圈落在谁身上、是不是紧急，再对照右侧威胁排序。

## 箭头：作战指向

虚线 + 终点实心三角 = 某一侧的作战指向或运动方向（不是坐标轴）。

- **红虚线 + 红三角**：美方指向  
- **蓝虚线 + 蓝三角**：日方指向  

一端大致在己方兵力附近，另一端指向要去的方向。悬停可读指向标签。  
做**意图研判**时，优先看箭头在说「往哪打、往哪走」，再看阶段与证据。

## 点开单位能看到什么

| 类型 | 弹层内容 |
| --- | --- |
| 舰船 | 名称；舰级与状态；航速（节）与航向；损伤（若有）；舰载机数（若有） |
| 在空机 | 名称；机型、高度（米）、航向 |
| 岸基 | 名称；设施类别 |

## 和任务怎么配合

- **威胁主界面**：高亮 + 关注/紧急区往往更扎眼；右侧 PRIORITY 点条目可在图上定位（彩色钉）。  
- **意图对照**：作战指向更关键；阶段在界面 PHASE 栏，地图本身不画节拍字。  
- 底图右上角可切卫星 / 其他底图，只改背景，不改符号含义。

## 读图顺序（建议）

1. 红蓝落点与高亮——敌我大致在哪、谁被点名。  
2. 圈——哪里被标成关注或紧急。  
3. 箭头——各方主要往哪指。  
4. 需要细节再点单位弹层。
