## 推理过程

本任务属 **VMMP_I.task = “意图研判”**，需在 **无交火、无空中活动、纯兵力展开阶段（T1）** 完成三重子判断：佯动/真实打击区分、作战方向判断、行动阶段推断。严格依据 VMMP 范式逐层展开：

1. **C/R/O 判断（认知锚定）**  
   - **C_I（认知元素）**：核心是 `CombatEntity`（四艘IJN航母 vs 三支USN TF + Midway）、`State`（全部静止/低速集结、无在空单位）、`Space`（经纬度集群分布）、`Time`（T1 初始切片，非动态序列）、`Evidence`（舰体位置/航向/载机数/编队齐速状态）、`Hypothesis`（如“南云东进为佯动”或“TF16/17西北待机为伏击准备”）、`Confidence`（当前无侦察接触，所有推断均为低置信度假设）。  
   - **R_I（认知关系）**：  
     - `Spatial`（红方四舰密集于29.15°N/179.75°W；蓝方TF16/TF17分处177.2°W与176.9°W，呈西北扇形包夹中途岛）→ 支撑**作战方向判断**；  
     - `Directional`（红方航向112.5°即东南向中途岛；蓝方TF16航向245°即西南、TF17航向284°即西偏北）→ 暗示运动趋势与拦截可能；  
     - `Comparative`（红方舰载机235 vs 蓝方234，数量相当但分布迥异：红方全在航母甲板/机库，蓝方约2/3在TF16/17、1/3在Midway岸基）→ 关键用于**佯动识别**（若红方仅以部分航母前出，其余隐蔽，则构成佯动证据）；  
     - `Associative`（IJN escort 多数航速0且与航母同向，表明“集结未完成”；USN护航舰“多数仍0 kn/航向0” vs “大部已15 kn同向”，反映编队成熟度差异）→ 关联**行动阶段推断**；  
     - `Evolutionary` & `Transition`（T1为“集结停泊→即将放飞侦察→搜索接触”阶段跃迁起点）→ 驱动**阶段推断**。  
   - **O_I（认知操作）**：按推理路径 `Identify → Trace → Compare → Relate → Infer → Verify` 执行：  
     - `Identify`：识别红方四航母同中心、同航向、不同航速（Kaga/Soryu=0 kn，Akagi/Hiryu=12 kn），蓝方TF16/17分离但均朝向中途岛；  
     - `Trace`：沿 `Directional`+`Temporal` 关系追踪航向矢量延伸线（红方112.5°指向中途岛东南象限；蓝方245°/284°指向其西北侧海空域）；  
     - `Compare`：用 `Comparative` 关系对齐红蓝航母数量、载机总数、空间离散度（红方高度集中，蓝方分散但有地理锚点Midway）；  
     - `Relate`：通过 `Associative` 将“航速0的护航舰比例”与“编队完成度”关联，再与“侦察机未放出”这一 `State` 关联；  
     - `Infer`：基于 `Directional`+`Spatial`+`Evolutionary` 推断——红方重心明确指向中途岛（非阿留申佯动），蓝方重心是“以岛为轴、舰队为弧”的防御性前置部署；  
     - `Verify`：用 `Support`/`Refutation` 关系检验假设——若红方真佯动，应有至少一艘航母脱离主群向北机动（但T1数据中无此迹象），故当前**无佯动证据**；所有推断均需标注 `Confidence` 为低（因无侦察反馈，属静态快照推演）。

2. **M 映射到视觉组织 T（拓扑落地）**  
   - `Spatial`+`Locate` → 映射至 **Position**（经纬度精确定位）；  
   - `Directional`+`Trace`/`Infer` → 映射至 **Position**（航向箭头起点）+ **Continuity**（航向延长线虚线）；  
   - `Comparative`+`Compare` → 映射至 **Alignment**（红蓝航母载机数并列柱状图、空间分布热力对比）；  
   - `Associative`+`Relate` → 映射至 **Connection**（航母-护航舰连线粗细表征协同度）、**Proximity**（编队内舰艇间距编码集结完成度）；  
   - `Evolutionary`+`Transition`+`Trace` → 映射至 **Continuity**（T1作为时间轴起点）+ **Hierarchy**（阶段标签“集结态→搜索态→接触态”灰阶降序）；  
   - `Support`/`Refutation`+`Verify` → 映射至 **Connection**（假设与证据的逻辑链）、**Salience**（被证伪的佯动假设加删除线高亮）；  
   - `Confidence`+`Verify` → 映射至 **Uncertainty**（所有推断结论旁置置信度滑块/色阶：灰色=低，浅蓝=中，无深色=高——此处全为灰色）。

3. **E 自检（匹配评价）**  
   - `SpatialFit`：经纬坐标直投地图，精度满足；  
   - `TemporalFit`：T1标为时间轴原点，无后续帧干扰，符合“初始态势”定义；  
   - `RelationFit`：航向线（Directional）、编队连线（Associative）、对比图表（Comparative）均显式编码对应关系；  
   - `ComparisonFit`：红蓝载机数、空间密度、航速离散度三组对比均通过 Alignment 实现；  
   - `EvidenceFit`：所有可视化元素均可回溯至原始 JSON 字段（如“Kaga 0 kn”→静止图标，“TF17 15 kn 同向”→箭头粗细统一）；  
   - `SequenceFit`：阶段推断仅呈现“T1：集结态”，未越界预测，符合 Evolutionary 关系的起点定位；  
   - `UncertaintyFit`：全界面无确定性断言，所有意图标签带置信度衰减标识；  
   - `ConsistencyFit`：红蓝配色（红#C00000/蓝#002060）、符号体系（航母=⚓、侦察机=✈️×0）、字体层级全统一。

### 1. 地图：放什么、如何编码（位置/航向/突出）

- **实体编码**：  
  - **红方（IJN）**：四艘航母以 **⚓红色实心图标** 表示，尺寸正比于舰载机数（Akagi 55→最大，Soryu 56→次大）；  
    - `Position`：精确落点于 JSON 中心坐标（29.15°N, 179.75°W），四舰以 **15km半径圆形聚类框** 包络，框内标注“Nagumo TF”；  
    - `Directional`：每舰叠加 **112.5°蓝色航向箭头**（长度=10nm），箭头末端延伸 **灰色虚线** 至中途岛海岸线（直观体现指向性）；  
    - `State`：Kaga/Soryu 图标外加 **静止环（⭕）**，Akagi/Hiryu 加 **匀速环（→）**，呼应“0 kn”与“12 kn”；  
    - `Uncertainty`：所有红方图标外围加 **15%透明度灰色晕圈**，表征“未侦察确认”。  
  - **蓝方（USN）**：  
    - TF16/TF17 以 **⚓蓝色实心图标** 表示，尺寸正比于舰载机数（TF16:159→大，TF17:75→中）；

### 2. 图表与指标：需要哪些图、KPI
- **左侧垂直面板（意图研判专用）**：  
  - **双轴对比柱状图**（Alignment）：  
    - X轴：红方四航母 / 蓝方TF16+TF17+Midway；  
    - 左Y轴（数量）：舰载机数（红235 / 蓝234），柱色分九七/零/九九式（红）与F4F/B-17/PBY（蓝）；

  - **空间密度热力图**（Comparative）：

  - **阶段推断仪表盘**（Hierarchy + Uncertainty）：
