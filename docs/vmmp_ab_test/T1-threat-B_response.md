## 推理过程

本任务属 **VMMP_W.task = "威胁分析"**，核心是为蓝方（USN）在T1初始态势下完成“开战潜力排序”，而非接触后应急响应。依据VMMP范式逐层展开：

- **C_W（认知元素）**：必须显式呈现的要素包括  
  `CombatEntity`（红方四航母实体、蓝方三航母+中途岛）、  
  `Capability`（舰载机数量/机型构成/起飞准备度）、  
  `State`（航速0/12/15 kn、集结/齐速/停泊状态）、  
  `Behavior`（航向112.5°指向中途岛 vs 蓝方245°/284°北偏西机动）、  
  `Space`（经纬度坐标、相对距离、方位角）、  
  `Time`（T1为静态切片，无动态时间轴，但隐含“发现窗口期”）、  
  `ThreatLevel`（非杀伤等级，而是“先手发现潜力”与“打击链启动能力”）、  
  `Priority`（需输出有序序列）、  
  `Confidence`（所有判断均基于导出数据，无侦察验证，故置信度中等偏低）。

- **R_W（认知关系）**：关键关系为  
  `Spatial`（南云中心29.15°N,179.75°W vs TF16/TF17/中途岛位置 → 决定雷达/水侦覆盖重叠区），  
  `Comparative`（红方4航母 vs 蓝方3航母；红方舰载235 vs 蓝方234；但红方Kaga/Soryu停泊→起飞准备度低于Akagi/Hiryu），  
  `Associative`（航母与其护航舰群、舰载机型号构成、航向一致性 → 构成作战编组单元），  
  `Ordering`（四航母间能力差异需线性排序），  
  `Hierarchical`（航母为威胁核心，护航舰为支撑层，水侦为感知延伸 → 非对等威胁层级）。

- **O_W（认知操作）**：严格遵循推理路径  
  `Identify` → 提取红方四艘航母为独立CombatEntity（非笼统“南云部队”）；  
  `Locate` → 基于经纬度定位各实体空间坐标（触发Spatial→Position映射）；  
  `Filter` → 按“是否具备即时起飞能力”过滤：Kaga/Soryu航速0且停泊 → 起飞准备延迟；Akagi/Hiryu航速12 kn且已齐速 → 具备快速放飞能力 → 触发Comparative→Salience映射；  
  `Compare` → 对比红方四航母舰载机总数（235）与蓝方（234），但更关键比“可首波起飞量”（Akagi 55 + Hiryu 54 = 109 vs Kaga+Soryu合计119但需调度时间）；  
  `Aggregate` → 将每艘航母的`Capability`（机型配比）、`State`（航速/齐速）、`Behavior`（航向112.5°）关联为“发现-打击链启动潜力”综合指标；  
  `Assess` → 评估每艘航母的ThreatLevel：以“单位时间内可投入搜索/攻击的航空兵力”为核心，叠加“航向指向性”（112.5°正对中途岛，利于前出侦察）；  
  `Rank` → 按ThreatLevel数值降序输出优先级；  
  `Verify` → 用“水侦搭载平台”（利根/筑摩）与“航向一致性”作为Support关系证据，佐证南云部队整体指向性；同时用“无在空单位”标注Confidence受限（无实时验证）。

- **M_W（映射规则）**：  
  - Spatial + Locate → 地图上精确Position编码；  
  - Comparative + Filter → 用Salience（如颜色饱和度/图标闪烁）突出Akagi/Hiryu；  
  - Associative + Aggregate → Grouping将每艘航母与其护航舰、水侦平台连线；  
  - Hierarchical + Assess → Hierarchy通过视觉层级（航母主图标 > 护航舰小图标 > 水侦微标）体现；  
  - Ordering + Rank → Ordering拓扑实现垂直列表排序，Salience强化Top-2；  
  - Support + Verify & Confidence → Connection线标注水侦平台，Uncertainty用半透明蒙版+文字标注“未验证航向持续性”。

- **E_W（评价）**：重点满足  
  `SpatialFit`（经纬度直投地图，误差<0.01°）、  
  `ComparisonFit`（四航母并列对齐，便于横向比较舰载数/航速）、  
  `AggregationFit`（Grouping清晰绑定航母-护航-水侦）、  
  `HierarchyFit`（图标尺寸/权重区分主次）、  
  `ScreeningFit`（Akagi/Hiryu高亮，Kaga/Soryu灰化）、  
  `RankingFit`（垂直列表+数字序号+色阶）、  
  `UncertaintyFit`（明确标注“无空中验证”“集结未完成”）。

## 态势界面方案

### 1. 地图：放什么、如何编码（位置/航向/突出）
- **底图**：太平洋西北部海图（范围25°–32°N, 175°W–180°W），投影采用等距圆柱（保留方位精度），标注经纬网格（5°间隔）。
- **实体编码**：
  - **红方航母**：四枚独立舰标（非集群符号），按实际经纬度精确定位：  
    - `Akagi`（29.15°N, 179.75°W）→ 深红色三角箭头，**加粗边框+脉冲光晕**（Salience），箭头方向112.5°，旁注“55↑（12 kn）”；  
    - `Hiryu`（同中心点微偏，按导出数据视为同位）→ 红色三角箭头，**加粗边框**，旁注“54↑（12 kn）”；  
    - `Kaga`/`Soryu` → 浅红色方形图标（非箭头），无方向线，旁注“63↓（0 kn）”/“56↓（0 kn）”，**灰化透明度30%**（Filter Salience）。  
  - **护航舰群**：以细虚线从航母中心放射连接至`雾岛`/`榛名`/`利根`等（Grouping），`利根`/`筑摩`额外叠加水滴形小图标（表示搭载水侦）。  
  - **蓝方力量**：TF16（双航母并排）、TF17（单航母）、中途岛（岛屿轮廓+跑道简笔画），全部用蓝色系，**不加方向箭头**（因航向未齐速，行为不确定性高），仅标坐标与航速。  
- **关键空间关系可视化**：  
  - 从南云中心向中途岛画一条**112.5°方位虚线**（Spatial Relation），终点标注“Midway 28.21°N, 177.38°W”；  
  - 标注南云中心至TF16/TF17的**大圆距离**（km），字体大小随距离衰减（Spatial Fit）。

### 2. 图表与指标：需要哪些图、KPI
- **主图表：威胁潜力雷达图（4维）**  
  每艘红方航母一个雷达图，共4个并列小图（Alignment支持Comparative），维度统一为：  
  ▪ 航空战力（舰载机总数×机型系数：九七式0.8/零式1.2/九九式1.0 → Akagi=55×1.02≈56）  
  ▪ 准备就绪度（航速12 kn=1.0，0 kn=0.3；齐速=1.0，未齐速=0.6）  
  ▪ 指向性（航向112.5°对中途岛夹角=0°→1.0；其他角度线性衰减）  
  ▪ 感知延伸（搭载水侦的护航舰数量：利根/筑摩=2 →1.0；其余=0）  
  → 综合得分=四维几何平均（Aggregation），直接支撑ThreatLevel量化。

- **KPI面板（顶部横栏）**：  
  - 【红方总潜力】235架（vs 蓝方234）→ 用黄底黑字，强调“势均”；  
  - 【红方即时可用】Akagi+Hiryu=109架（占46%）→ 红底白字，加叹号图标；  
  - 【发现窗口】南云水侦最大半径≈250 km → 计算并标注“当前水侦覆盖圈 vs TF16/TF17距离”，标红“TF16距南云中心≈220 km（临界）”；  
  - 【不确定性】“无空中验证 / 集结未完成 / 航向持续性未知” → 灰底斜体，带⚠️图标（UncertaintyFit）。

### 3. 布局：主辅视图如何安排
- **主视图（70%宽度）**：中央海图（含所有实体定位与连接线），**固定比例尺**（1°≈111 km），禁止缩放（避免空间失真）。  
- **左辅视图（15%宽度）**：垂直排序列表（Ordering拓扑），标题“红方威胁目标优先级（T1）”，条目：  
  `① IJN Akagi — 0.92★`（★=ThreatLevel雷达图综合分）  
  `② IJN Hiryu — 0.89★`  
  `③ IJN Kaga — 0.61★`  
  `④ IJN Soryu — 0.58★`  
  → 字体大小阶梯递减，①②行背景浅红，③④行背景浅灰（RankingFit + Salience）。  
- **右辅视图（15%宽度）**：四组并列雷达图（Alignment支持Comparative），每图下方标注舰名与得分，图例统一置于顶部。

### 4. 要突出的信息与不确定性如何表达
- **突出信息**：  
  - `Akagi`与`Hiryu`的**高亮处理**（脉冲光晕+加粗）直接响应Filter操作，表明其为“关键筛选结果”；  
  - “TF16距南云220 km”在KPI与地图上**双重标红加粗**，直指“谁先发现”的核心矛盾；  
  - 雷达图中`指向性`维度全为1.0（因航向一致），用深绿色填充，强化“南云整体指向中途岛”这一Behavior认知。

- **不确定性表达**：  
  - 所有红方实体图标添加**半透明灰色问号浮层**（Opacity=0.25），鼠标悬停显示：“T1切片，无实时侦察验证”；  
  - Kaga/Soryu的“0 kn”状态旁加注“*集结停泊，起飞准备延迟≥30 min（估算）*”，斜体小字；  
  - 地图底部固定栏：“⚠️ 当前态势为静态快照（T1），无运动矢量推演，所有航向/速度假设恒定——需后续切片验证”。  
  → 严格对应`Confidence`元素与`Verify`操作，通过`Uncertainty`拓扑实现。
