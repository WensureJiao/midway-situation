# 范式引入后的态势图改进说明

范式的 CROME 规范：先明确看什么（C）、用什么关系组织（R），再按任务路径做（O），把结论落到地图和高亮上（M），最后用本切片数据核对（E）。

改进的检验标准：

1. 推理流程是否完成了规范化。  
2. 对不同任务生成的态势图是否更有针对性。  
3. 与未引入范式之前相比，图上是否更明确地指向任务结果（而不是只是画面更整齐）。

说明：对照无范式生成（A）与注入 VMMP 后的生成（B）；威胁用 VMMP_W，意图用 VMMP_I；红方=美军（含中途岛），蓝方=日军。实验基线大模型为通义 qwen-plus（temperature≈0.2），A/B 仅差是否注入 VMMP。

建议先以 1～2 个时间片（如 T1、T81）做对照验证，不必一次铺开全部切片；全阶段跨切片总图暂不作为主展示。

## 地图上各个指标的含义

勿都理解成已交火。当前图上主要读这些（含悬停/点击明细）：

1. **范围圈（活动区）**：模型标出的一块「需要盯住的海域」，圆心在某支兵力或某个地点附近，常见是集结区、航母集群、岸基周边。四档分色：紧急酒红、高亮橙、中黄绿、低深绿（按威胁等级，不用红/蓝表示所属方）。威胁分析任务里范围圈比较重要。  
   - **悬停**：标签名 · 关注区/紧急区 · 约略半径（海里）。
2. **轴线（作战指向）**：表示某一侧的作战指向或运动方向，一端大致在己方兵力附近，另一端指向关注方向；红虚线偏美方，蓝虚线偏日方。意图研判任务里轴线更重要。  
   - **悬停**：轴线标签 · 「作战指向」。
3. **单位符号**：航母为正方形，其余水面舰为圆形，在空飞机为小三角，岸基（机场/防空）为金色较大符号；美方偏红、日方偏蓝。关键单位可有金色外沿强调（高亮）。  

   - **悬停（高亮单位）**：显示舰名，避免常驻标签搅乱画面。  
   - **点击弹层**：舰船为名称、舰级/状态、航速与航向、损伤与舰载机数（若有）；在空机为名称、机型、高度与航向；岸基为名称与设施类别。

后续还可继续丰富标注（发现扇区、接触线等）；任务本身也可再复杂化，使可呈现信息更接近完整 COP 界面。

## 观察视角（重要）

威胁分析与意图研判的推理过程都固定为**单一观察视角**（默认美方；若做日方实验则整篇只站日方）。  
只回答「这一方此时能怎样看、该怎样排、该怎样猜」，不并排写双方对称结论，也不假装同时掌握双方内部整备细节——那是上帝视角。早期切片（如 T1）日方未必已发现美航母，尤其不能用日方视角去「看穿」美方部署。界面右侧不再做红/蓝双视角切换。

## 一、规范化对比

本项目里其实有三层，不宜只说「有没有范式」：

- **本地基线**：不经过大模型，按切片几何与规则拼出态势骨架（单位落点、基础圈与指向、本地威胁排序等）。界面底栏固定为分布 · 排序 · 证据 · 阶段，右侧 PRIORITY / CORE；用来对照「没有 LLM 时图上至少有什么」。
- **A · 无范式**：同一套 LLM（通义 qwen-plus，temperature≈0.2）生成态势与推理，**不注入** VMMP。推理要求先写「结论」再写「过程」，但是自由叙述，禁止套 C/R/O/M/E 或固定步骤名。
- **B · 有范式**：同一 LLM，注入 VMMP_W（威胁）或 VMMP_I（意图）。同样先写结论，再按 C → R → O（逐步）→ M → E 写完，O 必须走任务路径。

没有范式时（主要指 A，本地则根本不写推理过程），模型往往直接给出判断：谁更危险、朝哪边去、是不是佯动、现在到了哪一阶段。中间很少写出「先看谁、怎么比、怎么筛」，步骤名也不固定。读者事后很难核对有没有漏筛、有没有跳步；若提示约束不严，还容易把己方和敌方视角写混，甚至滑向上帝视角双侧排序。

加上范式之后（B），必须先把路径走完，再把结论落到地图（高亮、作战指向、关注/紧急区）和扩展图上。本仓库实际路径为：

- **威胁（VMMP_W）**：Identify → Locate → Filter → Compare → Aggregate → Assess → Rank → Verify（识别 → 定位 → 筛选 → 比较 → 聚合 → 评估 → 排序 → 核对）。
- **意图（VMMP_I）**：Identify → Trace → Compare → Relate → Infer → Verify（识别 → 追踪 → 比较 → 关联 → 推断 → 核对）。

全程固定**美方单视角**：只写「我方此刻怎样看敌情」；威胁列表只排日方目标；意图用美方可见证据猜日方在做什么。对比页用顶部 A/B 切换同一布局，差异主要在推理是否可逐步核对，以及 B 是否多出按 M/T 选出的扩展图（方位雷达、证据构成饼、证据维度轮廓雷达等）。

这不保证史实一定更准，但更便于核对：有没有按任务筛排、有没有跳步、视角有没有跑偏。本地基线则提供「无 LLM」的几何参照，避免把一切画面差异都算成范式功劳。

## 二、威胁分析的推理过程

威胁任务固定站在**美方**视角，只回答三件事：日方关键威胁是谁、等级怎样（紧急/高/中/低）、右侧 PRIORITY 怎么排。不写「日方看美方」对称栏，也不把己方航母、中途岛写进威胁列表。

读现在的态势图时，主要看这几类标注是否跟结论对齐：

- **高亮（金色外沿）**：应对准筛出来的日方关键目标，而不是整片海「该亮的都亮着」。
- **作战指向（红/蓝虚线+三角）**：标美方或日方的进击/运动方向；威胁任务里可有可无，有则应能说清和排序的关系。
- **活动区（虚线圆）**：紧急酒红 / 高亮橙 / 中黄绿 / 低深绿；等级要写清，不能含糊成「随便画个圈」。
- **右侧排序与底栏条形图**：应只列日方目标，并与地图高亮、圈等级一致。

无范式（A）时，常见问题是高亮偏散、指向可有可无、圈的等级含糊，排序里偶尔混入己方单位。有范式（B）后，应按 VMMP_W 路径走完再落图：高亮对准筛出目标，圈带明确等级，排序严格「美方看日方」。这不保证史实一定更准，但更便于核对「图上亮的是不是刚排出来的威胁」。

（各时间片 A/B 对照仍可按实验笔记展开；排版时态势图对比宜放大局部细节。）

## 三、意图研判的推理过程

意图任务同样只站在观察者一方，回答：就这一方所能依据的态势，对方更接近哪一节拍、作战指向哪里、有无佯动、证据是否够。  
默认观察者为美方时：用美方位置、航向、在空与接触证据去推断日方意图；不并行写「美方想干什么 + 日方想干什么」的双侧散文。

路径仍走识别 → 追踪 → 比较 → 关联 → 推断 → 核对。有范式后应突出支撑该单方假设的关键单位，用作战指向标方向，关注区只在确有聚集时使用，并给出阶段与证据，而不是用威胁排序代替意图问题。证据区宜用表格/统计图，少用大段卡片堆叠。

## 四、图表与界面组织

针对一个时间片的一次任务，应生成**包含态势图（地图）+ 多个统计图表**的同屏界面，而不是把统计图单独抽离成另一套叙事。

图种尽量丰富：已启用柱状、分组柱、条形、折线、多序列折线、面积、饼图、散点、雷达、热力等常见类型；桑基等可后续再加。范式的有效性还应体现在**能否按任务选出合适图种**上——例如威胁任务用条形做排序、散点看等级与证据关系、热力做目标×等级矩阵；意图任务用柱状标阶段、分组柱看指向、饼/雷达看证据结构。对比页中，无范式一侧（A）只给基础图，有范式一侧（B）按任务展开更贴切的图种组合，便于对照「选图」差异。全阶段跨切片总图仍可后置。

## 五、小结（表述需谨慎）

目前较稳妥的结论是：注入 VMMP 后，推理步骤更可核对，地图标注更常对准关键目标与任务问题；量化“全面优于无范式”尚需更多切片与盲评支撑。对比截图请放大细节，避免仅凭缩略观感下判断。
