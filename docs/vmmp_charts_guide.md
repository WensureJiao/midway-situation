# 中途岛态势统计图说明（参考稿）

> 本文说明系统中**新接入的统计图**：图种白名单、对比页认知图槽、图种库 `/charts`。  
> 红方 = 美军（USN，含中途岛），蓝方 = 日军（IJN）。  
> **A** = 无 VMMP 范式；**B** = 注入 VMMP（威胁用 VMMP_W，意图用 VMMP_I）。

---

## 1. 设计原则（两层）

统计图不追求「一次画满很多种」，而是拆成两层：

| 层次 | 目的 | 入口 |
|------|------|------|
| **图种语法** | 系统支持哪些常见统计图（白名单） | `/charts` |
| **任务图槽** | A/B 左右同构，用认知结果拉开范式差异 | `/compare` |

另外：

- **事实图**：来自切片 `pack`（舰数、在空、机型构成）。同一切片上 A/B 兵力相同，不能单独证明范式改进。  
- **认知图**：来自该侧生成的 `threat_ratings` / `map`（高亮、轴线、圈）/ 阶段推断。左右标题与图种相同，只比数值。  
- **不为图表而图表**：横条与竖柱同类；0/1/0 的「阶段柱」已弃用；环图、散点、堆叠柱因与饼图/条形重复，本轮不启用。

### 1.1 选图思维流程（对比页）

对比页选图不是「能画什么就堆什么」，而是：

1. **定问句**（威胁：谁最急 / 相对岛在哪；意图：阶段·指向·证据）  
2. **定认知操作**（Locate / Compare / Rank / Relate / Verify …）  
3. **映射视觉拓扑 T**（Position、Alignment、Ordering、Connection …）  
4. **落到图种槽**（散点、横条、柱、雷达、饼 …）  
5. **常驻 vs 扩展**：无范式只出常驻，保证 A/B 可比；有 VMMP 时 M 规则激活的拓扑才打开扩展槽（威胁常见「相对中途岛方位」雷达；意图常见证据饼 + 证据轮廓雷达）

实现：`src/lib/vmmpChartSelect.ts`（`selectChartSlotIds`）。评价时看扩展图是否**对准任务几何**，不看图种数量。T81/T145 实例见 `docs/T81_T145_vmmp_ab_三层差异说明.md` §4.0。

## 2. 图种白名单（7 类）

| 图种 | 主要用途 |
|------|----------|
| 柱状图 | 威胁等级分布；主台水面舰/在空计数 |
| 分组柱状 | 两视角目标数；美/日作战轴线数 |
| 条形图 | 红看蓝 / 蓝看红威胁排序（条长=等级分，颜色分档） |
| 折线图 | 跨切片在空总数、舰数走势 |
| 多序列折线 | 跨切片美/日在空对比 |
| 面积图 | 跨切片意图阶段编码 |
| 饼图 | 证据构成、地图编码；红/蓝舰载机就绪构成 |

**不算统计图种：** 意图任务的「战役阶段」用分段高亮条（集结 / 搜索 / 接触三选一），不用柱状图。

## 3. 对比页 `/compare`（实验主战场）

左右各一栏：A 无范式，B 有 VMMP。图槽由服务端从该侧 `SituationViewSpec` 推导，模型输出 `charts: []`。

### 3.1 威胁任务（3 张）

| 图 | 图种 | 数据来源 | 怎么读 / 看什么差异 |
|----|------|----------|---------------------|
| 威胁等级分布 | 柱 | `threat_ratings` 按紧急/高/中/低计数 | 是否从「高」扎堆拉开层次 |
| 视角目标数 | 分组柱 | 红看蓝 / 蓝看红条数 | 两视角是否都筛到、是否漏一边 |
| 地图编码 | 饼 | 高亮单位数、轴线数、关注圈数 | 筛排结果有没有落到地图上（不是全场舰数） |

威胁排序另有列表面板（可按视角切换），不重复画一张条形。

### 3.2 意图任务（2 张图 + 1 条阶段条）

| 呈现 | 形式 | 数据来源 | 怎么读 / 看什么差异 |
|------|------|----------|---------------------|
| 战役阶段 | 分段条 | 由 `phase_label` / 叙述推断 | 亮哪一格；左右是否跳步或判错 |
| 作战指向 | 分组柱 | `map.axes` 按 USN/IJN 计数 | 美/日各画了几条方向轴；是否仍「只指中途岛」 |
| 证据构成 | 饼 | 从轴/高亮/圈抽出的方向、关键实体、活动区 | 悬停扇区可看具体条目；叙述全文不进饼图 |

## 4. 图种库 `/charts`（语法与真实切片）

用于展示白名单图种，数据用真实切片，不是假数。

### 4.1 操作

- 时间片按钮：T1 / T21 / T81 / T145 / T193 → 只看**该片**图。  
- 「时间线 T1→T193」按钮（与切片按钮齐平）→ 只看**跨切片**图。  
- A / B 切换：认知类图随侧变化；兵力类图两边相同。

### 4.2 单切片视图（示例组合）

| 图 | 图种 | 数据 |
|----|------|------|
| 威胁等级分布 | 柱 | 该侧威胁生成的 ratings |
| 视角目标数 | 分组柱 | 同上 |
| 红看蓝 · 威胁排序 | 条形 | 美方视角下日方目标；条长=等级分（紧急4…低1），颜色分档 |
| 蓝看红 · 威胁排序 | 条形 | 日方视角下美方（含中途岛）目标 |
| 红方 / 蓝方舰载机（就绪） | 饼 | 该片 `pack` 机型构成（同机型不同 ready_min 已合并） |
| 意图证据构成 | 饼 | 该侧意图生成；悬停显示轴/高亮/圈明细 |

### 4.3 时间线视图

| 图 | 图种 | 数据 | 备注 |
|----|------|------|------|
| 在空飞机总数 | 折线 | 各片 pack 双方 airborne 之和 | 与 A/B 无关 |
| 美/日在空数 | 多线 | 各片 USN / IJN airborne | 与 A/B 无关 |
| 意图阶段编码 | 面积 | 各片意图生成推断：1=集结，2=搜索，3=接触 | 随 A/B 变 |
| 水面舰艇总数 | 折线 | 各片 pack 双方舰数之和 | 纵轴在数值接近时自动收紧，避免 48～49 贴顶看不清 |

## 5. 主生成台（对照）

主界面仍固定四张**兵力事实图**（与 A/B 范式实验分流）：

1. 水面舰艇数量（柱）  
2. 在空飞机数量（柱）  
3. 红方舰载机机型构成·就绪（饼）  
4. 蓝方舰载机机型构成·就绪（饼）  

对比页关闭这四张，改用第 3 节任务图槽。

## 6. 写报告时可引用的对照句式（示例）

- 「同一切片兵力事实相同，B 侧威胁等级分布从『高』扎堆变为紧急/高/中分层，说明筛选层次改善。」  
- 「视角目标数上，A 侧某视角为 0 或混入己方（需结合排序列表核对），B 侧两视角均有条目且更干净。」  
- 「意图证据构成饼图悬停可见轴线标签与高亮实体；B 侧方向类证据更完整。」  
- 「跨切片阶段面积上，B 侧更贴近 T1→T193 战役进程（集结→搜索→接触）。」

注意：统计图是**放大镜**，主证据仍是地图编码 + 推理文字；若两侧 ratings 本身接近，图也会接近。

## 8. 修订记录（可按需删）

- 去掉假数据示意，改为真实切片 pack + A/B 态势。  
- 证据构成：去掉「叙述依据」扇区（几乎恒有/恒被截断，无区分度）；悬停展示明细。  
- 阶段：分段条替代 0/1/0 柱。  
- 时间线与单片切换：按钮齐平，不在每个切片下重复挂时间线。  
- 不启用：环图、散点、堆叠柱（与饼图/条形信息重复）。
